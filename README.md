# techoship/.github

This repository holds Techoship's GitHub organization profile — the page people see at
[github.com/techoship](https://github.com/techoship). GitHub renders `profile/README.md` there.

## Keeping it current

- Prices and service names come from techoship.com. If they change on the site, update the
  "Start small" section here too.
- Links carry `utm_source=github&utm_medium=profile`, so visits from this page show up with
  their source in the website's admin under Visitors.
- Logos are loaded from techoship.com, so a new logo on the site appears here automatically.
